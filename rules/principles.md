# Principles

모든 코드에 항상 적용되는 핵심 원칙. TypeScript 모노레포 npm 패키지 기준으로 정의한다.

## 1. 단일 책임
- 하나의 패키지, 모듈, 함수는 하나의 역할만 수행한다
- 패키지 경계를 넘어 역할을 겸하지 않는다

## 2. 의존성 방향
- `packages/*` 간 의존은 단방향만 허용한다. 순환 의존은 금지한다
- 상위 계층이 하위 계층을 의존한다. 역방향 금지
- 내부 공용 패키지(config, tsconfig, eslint)는 라이브러리 패키지를 의존하지 않는다

## 3. 명시적 Public API
- 패키지의 외부 노출은 `index.ts`를 통해서만 수행한다
- 내부 구현 파일을 외부에서 직접 import하지 않는다
- export되지 않은 것은 공개 API가 아니다

## 4. 타입 계약 안전
- 공개 API는 명시적 타입 선언을 가진다 (추론에 의존하지 않는다)
- `any`, `@ts-ignore`, `@ts-expect-error` 사용 금지. 필요 시 근거를 주석으로 남긴다
- `unknown`은 허용되며 내부에서 좁혀 사용한다

## 5. 중앙 집중 관리
- 빌드, 린트, 타입스크립트 설정은 내부 공용 패키지에서 공유한다
- 매직 넘버/매직 스트링, 환경 변수 리터럴은 상수 모듈에 모은다
- 동일한 로직을 여러 패키지에 중복 구현하지 않는다

## 6. 최소 범위 변경
- 수정은 요청된 범위로 한정한다. 부수효과(무관한 포매팅, 리팩토링) 금지
- 패키지의 공개 API를 바꾸는 변경은 의도적이고 명시적이어야 한다
