# 테스트 (C7)

## When to Apply
- 새 기능/버그 수정과 함께 테스트를 작성 또는 수정할 때
- 테스트 설정(`vitest.config.*`, `jest.config.*` 등)을 변경할 때

## MUST
- 각 패키지는 자체 테스트 스크립트(`test`)를 `package.json`에 정의한다
- 공개 API는 외부에서 사용하는 방식 그대로(패키지 이름으로 import) 테스트한다
- 부수효과가 있는 테스트는 격리한다 (글로벌 상태 변경 후 복구)
- 테스트는 결정적이어야 한다. 시간/난수/네트워크는 고정 또는 mock 처리한다

## MUST NOT
- 테스트에서 내부 구현 파일을 상대 경로로 import하지 않는다 (패키지 경계를 지킨다)
- `it.skip`/`describe.skip`을 설명 없이 커밋하지 않는다
- 통과하지 않는 테스트를 커밋하지 않는다 (local 전용 실패 테스트 금지)

## PREFER
- 단위 테스트는 파일/함수 단위, 통합 테스트는 패키지 단위로 분리한다
- 테스트 픽스처는 `__fixtures__/`에 모은다
